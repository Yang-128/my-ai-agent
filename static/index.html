Connect an API key

Create a key with your provider. On the computer running My AI Agent, open the project’s .env file and set the matching entry to your key.

  • OpenRouter keys · OPENROUTER_API_KEY
  • Groq keys · GROQ_API_KEY
  • Google AI Studio keys · GEMINI_API_KEY

Save the file, restart the server, and refresh this page. The connection status updates when the app reloads.
